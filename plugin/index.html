What agents can use

Anything an agent reads here is sent to that agent's AI provider. With Claude Code, that means Anthropic's servers. This happens even when KAI is set to Local-Only, because the agent runs outside KAI. Only turn on what you are happy to share.

KAI's models and privacy status are always included. Turn on other plugins one by one.

Port

The bridge listens on 127.0.0.1 only, so other computers cannot reach it.
